# Mio Voice V1 Physical-Device Evidence Record

Each required browser/device family must have a traceable acceptance record. Required families remain iOS Safari, desktop Safari and Chromium. Each record requires at least three completed samples, interruption recovery, long-session stability, zero rebuffers, zero degraded samples, a non-empty run reference and verification timestamp.

Use a sanitized run/report identifier as the reference. Do not attach raw microphone audio, synthesis audio, transcript text, account/session identity, provider credentials or speaker biometric information.

A repository test can validate the record format but cannot create physical-device evidence. Evidence is valid only after the corresponding real browser/device run occurs.
