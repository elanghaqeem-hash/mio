# M-2.02a — Opt-in Local Chat UI

Mio CI 44696292766 validated existing ModelRouter native integration. Chat Studio now offers an explicit NATIVE LOCAL toggle, disabled during request, and invokes ModelRouter.generateNativeLocal with bounded recent conversation history. The default AgentOrchestrator and its settings remain unchanged; no cloud fallback is used on local route. Native chat explicitly skips project knowledge and memory envelopes until a governed context path exists. Failed local inference is shown without synthesizing success. UI is a renderer proof of integration; direct renderer loopback fetch may be blocked by browser origin/CSP, so this is NOT verified Windows desktop end-to-end. Before release, move localhost inference to authenticated, narrow Electron-main IPC; add stop, timeout, concurrency, renderer sender and live Ollama tests. No runtime mutation activation or deployment; Takane untouched.
