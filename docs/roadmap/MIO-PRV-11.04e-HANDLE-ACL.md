# PRV-11.04e — Handle-bound security descriptor diagnostic

Uses GetSecurityInfo on a native directory handle with READ_CONTROL and bounded descriptor extraction. Checks expected owner, protected and present non-null DACL, exact single owner allow ACE and inheritance flags. Fixture modifies ACL while the original handle remains open, expects denial on inspection, then restores and rechecks same identity. This is a restrictive fixture policy only; not equivalent to effective token access, atomic ACL/write enforcement or trusted ancestor traversal. Privileged/same-user attackers, changes after inspection, parent-to-child binding, real journal integration, parser parity and physical power-loss durability remain open. Keep CHECKPOINT_DURABILITY_UNSUPPORTED_WINDOWS. CI pending. No deployment.
