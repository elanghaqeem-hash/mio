# M-2.02a — Independent Desktop AI Runtime (read-only chat)

Baseline Mio CI 44696292766 passed M-2.01c application router integration. The Electron desktop now has a separate, explicitly enabled native chat path: ChatStudioView NATIVE LOCAL ON -> renderer gateway -> context-isolated preload -> trusted main-frame IPC -> Node main NativeDesktopChatService -> native cognitive model provider -> fixed loopback Ollama `http://127.0.0.1:11434` -> `qwen2.5:3b`. It retains system/user/assistant message roles. Browser-only builds retain existing opt-in native router behavior.

IPC validates an exact text-only request envelope (1-12 messages, 32k total chars, final user message), uses one in-flight request, a 120-second deadline, and denies new work after main-process STOP (including system-tray STOP and quit). It never accepts a model endpoint, file path, tool call, provider credentials or remote fallback from the renderer. Main-process abort and post-abort response denial are in place. A simulated Electron IPC service regression has been added to Mio CI; results pending. This is NOT a proof of live Ollama inference, GPU performance, robust streaming or cross-process shutdown of the Ollama server. Existing Windows checkpoint durability and dependency vulnerabilities remain separate production blockers.

Manual acceptance: (1) install Ollama and `ollama pull qwen2.5:3b`, (2) run desktop Electron, (3) enable NATIVE LOCAL, (4) send a two-turn Indonesian chat, (5) verify no remote provider traffic, (6) disconnect Ollama and verify explicit error, (7) STOP MIO during inference and confirm no late reply, (8) check Windows and Electron build/test gates. Do not deploy or merge without verified CI and live Windows acceptance.
